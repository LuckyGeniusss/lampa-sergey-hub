# Wazo TV — Ирландские каналы

Плейлист: `https://raw.githubusercontent.com/LuckyGeniusss/lampa-sergey-hub/main/iptv/wazo_ireland.m3u`

Проверено из Ирландии (Mac mini, 31 октября 2026) декодированием кадров FFmpeg:

- **TG4** — прямой видеопоток Brightcove, проверка прошла.
- **Oireachtas TV** — поток на `oirtv.oireachtas.ie/hls_2.m3u8`, проверка прошла; HLS media sequence изменяется, поток живой. `hls_1` и `hls_3` — другие варианты качества **того же канала**, не отдельные передачи.

Другие кандидаты (не добавлены): RTÉ One / RTÉ2 / RTÉ News (нет работающего прямого HLS), RTÉjr (401), Virgin Media 1–4 (ошибка воспроизведения), старые ссылки Oireachtas через CloudFront (404). Для них использовать официальные RTÉ Player / Virgin Media Play / Oireachtas сайт, а не неподтверждённые M3U-адреса.

Источники проверки: IPTV-org Ireland, IPTV-org Irish language, Free-TV Ireland, официальный домен Oireachtas. Международные каналы в каталоге Ireland не являются автоматически ирландскими телеканалами.

Скрипт `check_ireland.py` заново загружает указанные каталоги, проверяет кадры, а `build_wazo.py` при еженедельной пересборке включает подтверждённые каналы в `wazo_ireland.m3u` и общую категорию `Ирландские каналы`.

Доступность потоков, географические ограничения и права могут меняться. Наличие записи в M3U не гарантирует доступность в другой стране или позднее.

## Проверка на Fire TV Stick (31.10.2026, 10:14–10:16 UTC)

- Wazo TV 2.5.5, плагин Wazo 1.5.10: в IPTV отображается отдельный плейлист **«Wazo TV — Ирландские каналы»** и категория **«Ирландские каналы»**, 2 записи.
- **TG4**: воспроизводилось непосредственно в плеере Fire Stick, 1920×1080; в журнале `[Player] start playing`.
- **Oireachtas TV**: воспроизводилось непосредственно в плеере Fire Stick; `[Player] start playing`, скриншот показал живое изображение парламентской трансляции.
- Сохранены оригинальные пользовательские IPTV-плейлисты. В общей IPTV-базе 2340 URL (ранее 2339; добавлен Oireachtas TV, TG4 был).
- У TG4 API телепрограммы может возвращать `Not found`; это не помешало запуску видео и не является ошибкой HLS.
