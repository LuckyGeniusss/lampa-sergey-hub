# Wazo TV — единый проверяемый IPTV-плейлист

**Плейлист:** https://raw.githubusercontent.com/LuckyGeniusss/lampa-sergey-hub/main/iptv/wazo_tv.m3u

**Телепрограмма (EPG):** https://raw.githubusercontent.com/LuckyGeniusss/lampa-sergey-hub/main/iptv/wazo_epg.xml.gz

## Актуальная статистика

- [Проверенные каналы, категории и источники](https://raw.githubusercontent.com/LuckyGeniusss/lampa-sergey-hub/main/iptv/wazo_status.json) — поля `date_utc`, `working`, `groups`, `sources`.
- [Покрытие телепрограммой](https://raw.githubusercontent.com/LuckyGeniusss/lampa-sergey-hub/main/iptv/epg_status.json) — поля `streams`, `with_programme`, `programmes`.

Количество потоков меняется после проверки; старые фиксированные цифры и таблицы намеренно удалены. Все категории — ирландские, украинские, русскоязычные, фильмы, сериалы, детские, новости, спорт и другие — находятся **в одном M3U**, а не в отдельных списках.

## Обновления и устойчивость

- GitHub Actions перепроверяет каналы еженедельно и обновляет XMLTV ежедневно; локальная проверка из Ирландии — отдельное задание Mac mini.
- Плейлист публикуется только при достаточном числе работающих потоков, сохранении основных категорий и отсутствии подозрительной массовой потери ссылок.
- Кандидаты из предыдущего кеша и прежнего плейлиста повторно проверяются; непроверенные потоки автоматически не объявляются работающими.
- Дубли URL и локальные/частные IP-адреса отфильтровываются. Обновление EPG не меняет сами URL или порядок каналов.
- Отдельные провайдеры могут временно возвращать HTTP 403 или ограничивать вещание по стране. Проверка FFmpeg из Ирландии не гарантирует постоянное воспроизведение на каждом устройстве.

Результат последней проверки следует смотреть в JSON выше, а не в устаревшей статистике приложения или старых инструкциях.
