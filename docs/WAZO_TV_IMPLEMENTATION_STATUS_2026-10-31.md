## Выявленные первопричины и незавершённые задачи

### A. IPTV отображает старые 537 каналов — НЕ ИСПРАВЛЕНО
- IPTV-плагин использует **две разные сущности**: список добавленных M3U (`Lampa.Storage['iptv_playlist_custom']`) и активный плейлист с локально сохранённым разобранным содержимым (`DB.playlist`).
- В текущем APK новые адреса добавляются правильно, но старые данные загрузки остались с **30.10.2026 ~15:53**, а для плейлиста стоит `Обновлення — Ніколи` (никогда). На ТВ до сих пор отображается `Усі канали: 537`, несмотря на 1495 доступных записей в GitHub.
- В IPTV: нажать Back из списка каналов → экран `Виберіть плейлист`. Там присутствуют **Wazo TV — кино, сериалы и детские** и **Wazo TV — украинские, русскоязычные и ирландские**. Основной список уже помечен «Активно», но содержит старый кеш.
- На карточке основного M3U выполнить **долгое нажатие** → `Оновлення` → `Завжди` или `День`; затем `Видалити кеш`/«Очистить кеш» (только кеш этого списка), выбрать основной список заново и проверить число каналов.
- Удалить из истории только явно лишние пользовательские плейлисты; не удалять действующие два Wazo. Перед очисткой желательно сохранить список.
- Код: `cub.best/plugin/iptv`, компонент `PlaylistItem.displaySettings()` содержит выбор `update: ['always','hour','hour12','day','week','none']` и `DB.deleteData('playlist', id)` для очистки кеша. 
- Проверить после перезапуска Fire Stick и в реальном проигрывателе несколько каналов из разных источников.

### B. Фильмы и лишняя кнопка S Online — ОСНОВНЫЕ ОШИБКИ ИСПРАВЛЕНЫ
- **Причина 1:** Wazo 1.5.5 был направлен на `https://beta.l-vid.online`. `/lite/withsearch` выдавал `accsdb:true` с требованием Telegram-входа, а не источники.
- **Исправлено:** плагин Wazo **1.5.7** опубликован в `js`; восстановлен наш `https://sergey-online-backend.onrender.com`. На нём `/healthz` — 200, `/lite/withsearch` — список источников без требования Telegram, `/lite/events` и поиск фильмов отвечают. В скрипте улучшен порядок резервных источников, выбранный вручную источник не сбрасывается автопереключением.
- **Причина 2:** собственный APK дополнительно внедрял `https://skaz.tv/onlines.js`, показывавший кнопку **S Online**. Этот отдельный сервер `onlinecf7.skaz.tv` требовал стороннюю авторизацию.
- **Исправлено:** APK **Wazo TV 2.5.2**, пакет `ie.siaivo.tv`, собран из APK 2.5.0 точечным патчем DEX, без удаления данных, убрано внедрение S Online, обновлён URL плагина с query `?v=20261101`. Оригинальный APK сохранён на Mac, подпись того же Android debug-сертификата, DEX SHA1/Adler32 и подпись APK проверены.
- **Проверка источников:** для `The Matrix` (1999) `vkmovie` отдал HTTP 206 `video/mp4`, FFprobe проверил H.264 1920×800 + AAC; `zagonka` отдал HTTP 200 HLS, FFprobe проверил H.264 + AAC. `collaps` и ещё часть баланcеров возвращают HTTP 424/пустые ответы — их нельзя считать рабочими только потому, что они числятся в каталоге.
- **На самом Fire Stick**: открыл карточку «Матрица» → Wazo → Zagonka → «Многоголосый Закадровый» → плеер; логи `[Player] video loadeddata`, `[Player] start playing`, реальные видеокадры на экране. После выхода плеер запомнил последнюю озвучку.
- **Ограничение:** один воспроизведённый фильм не означает, что доступны все фильмы и сериалы. Проверку источников по каждому конкретному названию и озвучке нужно продолжать. Новые мультфильмы 2026 года могут быть недоступны, даже если API каталога работает.
- Исходник точечного исправления: `scripts/build_wazo_hotfix.py`; APK на рабочем SSD `build/WazoTV_2.5.2.apk`.

### C. Projectivy Premium — ОЖИДАНИЕ
- По официальному `https://premium.projectivylauncher.com/` внешние продажи временно приостановлены из-за платёжного провайдера. Google Play есть не на каждом Fire Stick. Не устанавливать модифицированные Premium APK и не менять прошивку ради картинок.
- Без Premium Projectivy показывает стандартные широкие баннеры некоторых приложений; собственная иконка Wazo TV остаётся квадратной. Не утверждать, что все карточки одной формы.
