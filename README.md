# Sergey Online Hub for Lampa

Версия 0.1.0.

## Что делает эта версия

Это один "загрузчик-хаб" для Lampa. Вы устанавливаете в Lampa только `plugin.js`, а в настройках хаба указываете до 8 прямых HTTPS-ссылок на другие JS-плагины Lampa. При старте Lampa хаб автоматически загружает включённые плагины.

Это удобно, если вы хотите держать на приставке только одну вручную установленную ссылку.

## Важно

Версия 0.1.0 НЕ объединяет результаты разных онлайн-плагинов в один общий список. Она объединяет установку и автозагрузку. Для настоящего общего поиска нужен отдельный адаптер для каждого источника, потому что у разных плагинов разные внутренние API.

Используйте только те источники, к которым у вас есть право доступа, и соблюдайте лицензии исходных проектов.

## Установка

После публикации репозитория на GitHub Pages добавьте в Lampa:

`https://YOUR_GITHUB_LOGIN.github.io/lampa-sergey-hub/plugin.js`

или через jsDelivr:

`https://cdn.jsdelivr.net/gh/YOUR_GITHUB_LOGIN/lampa-sergey-hub@main/plugin.js`

Далее:

Настройки → Sergey Online Hub → вставьте URL источников → перезапустите Lampa.
